# 正六边形到正方形：数学构造与验证

## 状态

`implemented`。本案例已经完成精确坐标恢复、初末覆盖、面积、刚体、铰链和连续路径验证，并已接入三阶段教学界面。

## 来源与模型边界

构造来自 Erik D. Demaine、Martin L. Demaine、David Eppstein、Greg N. Frederickson、Erich Friedman 的论文 *Hinged Dissection of Polyominoes and Polyforms*（2003）Figure 37：

<https://arxiv.org/abs/cs/9907018>

论文将该模型明确归类为不翻面的 swing-hinged，并允许运动中拼块重叠，即 wobbly hinged。项目没有复制或嵌入论文插图；公开的 TeX/EPS 源只用于确认 Figure 37 的割线和铰链拓扑，代码使用下述根式坐标独立重建。

该早期 arXiv 稿件采用 arXiv 的 assumed non-exclusive distribution license。项目仅实现公开的数学关系并保留完整学术署名，不把论文正文或图形素材再发布为项目资产。

## 精确坐标

令源正六边形边长为 `1`，并定义：

```text
r = √3
q = 1/2 √(6√3 - 9)
```

源正六边形上半部的关键点为：

```text
LM = (-r/2, 0)       LU = (-r/2, 1/2)
T  = (0, 1)          RU = ( r/2, 1/2)
RM = ( r/2, 0)
A  = (-r/4, 3/4)     B  = (r/4, 3/4)
P2 = (r/4+q/2, 0)    P4 = (-r/4+q/2, 0)
P3 = P4 + (3/4, q/2)
```

下半部是这些点绕原点旋转 `π` 的像。十块按下列顺序组成论文中的闭环：

```text
S3, S1, S5, S4, S2, -S3, -S1, -S5, -S4, -S2
```

其中：

```text
S1 = [A,T,B]
S2 = [LM,LU,A,P4]
S3 = [B,RU,RM,P2]
S4 = [P4,P2,P3]
S5 = [A,B,P3,P4]
```

## 目标正方形

取正方形相邻边向量：

```text
u = (3/2, q)
v = (q, -3/2)
```

由 `q² = (6√3-9)/4` 可得：

```text
u·v = 0
|u|² = |v|² = 3√3/2
```

所以 `[0,u,u+v,v]` 是边长平方为 `3√3/2` 的正方形，面积正好等于边长为 `1` 的正六边形面积 `3√3/2`。

目标内部点和逐块对应关系完整保存在 `src/cases/research/hexagon-square.js`。每一块的全部两两顶点距离在初末构型中相同；对应变换的行列式为 `+1`，因此不含镜像或翻面。

## 铰链拓扑

Figure 37 给出十铰链闭环。论文说明可在任一铰链处分开得到可扩展链；本实现断开 `RM` 处，只保留以下九个平面转动铰链：

```text
piece01 —B— piece02 —A— piece03 —P3— piece04 —P4— piece05
        —LM— piece06 —nB— piece07 —nA— piece08 —nP3— piece09
        —nP4— piece10
```

被断开的两个端点在 `t=0` 和 `t=1` 均重新重合，但在运动途中不作为机械约束。

## 运动学

第一块固定。设第 `i` 个铰链的源坐标为 `hᵢ`，相邻拼块最终姿态角之差为 `αᵢ`。递推刚体变换为：

```text
T₁(t) = identity
Tᵢ(t) = Tᵢ₋₁(t) ∘ RotateAround(hᵢ₋₁, smoothstep(t) αᵢ₋₁)
```

本构造恢复出的九个相对终端转角为：

```text
[π, 0, π, π, π, -π, 0, π, π]
```

每个变换均为二维旋转和平移的复合，因此刚体形状严格不变；递推时相邻两块使用同一旋转中心，因此九个铰链在全部 `t∈[0,1]` 上解析地重合。正弦、余弦和 `smoothstep` 都是连续函数，所以路径连续。

该路径遵循论文允许中途重叠的 wobbly 模型。101 点碰撞采样观察到中间存在正面积重叠，因此界面文案明确披露这一点；项目没有把它描述成无碰撞运动。

## 自动化验证

`tests/hexagon-square-research.test.js` 验证：

- 分块、源正六边形和目标正方形面积相等；
- 初态十块的并集精确覆盖正六边形，且无正面积重叠或越界；
- 终态十块的并集精确覆盖正方形，且无正面积重叠或空缺；
- 101 个运动采样中所有拼块保持边长与面积；
- 101 个运动采样中九组铰链两侧坐标误差小于 `1e-7`；
- 被断开的闭环端点在初态和终态闭合；
- 1001 个采样之间没有姿态跳变。

`tests/hexagon-square-case.test.js` 另外验证正式案例配置、屏幕坐标求解器和终态正方形外包框。离散采样用于捕获实现错误；路径连续性的数学依据是上面的递推旋转公式，而不是仅凭采样推断。
